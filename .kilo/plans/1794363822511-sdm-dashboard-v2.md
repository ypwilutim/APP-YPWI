## JavaScript Architecture (sdm-dashboard-v2.js)

### 1. Core Module Pattern
```javascript
const SDMDashboard = (() => {
  // Private state
  let state = { currentTab: 'dashboard', currentTenant: '', user: null, isSdmPusat: false };
  
  // Private methods
  // Public API
  return { init, showTab, ... };
})();

document.addEventListener('DOMContentLoaded', SDMDashboard.init);
```

### 2. State Management
- `state.currentTab` - active tab
- `state.currentTenant` - selected tenant filter
- `state.user` - decoded JWT payload
- `state.isSdmPusat` - boolean for SDM Pusat access
- `state.charts` - { attendance, kpi } Chart.js instances

### 3. Core Functions

#### Initialization
- `init()` - Decode token, verify access, load user info, setup event listeners, load default tab

#### Tab System
- `showTab(tabName)` - Hide all tabs, show selected, update nav active state, call tab-specific loader
- `onTenantChange()` - Update tenant filter, reload active tab data

#### API Layer
- `api(endpoint, options)` - Wrapper with auth header, error handling (401/403), JSON parsing
- `getAuthHeader()` - Bearer token from localStorage/sessionStorage

#### Modal Helpers (CONSISTENT PATTERN)
```javascript
function showModal(id) {
  document.getElementById(id).classList.remove('hidden');
  document.getElementById(id).classList.add('show');
}
function hideModal(id) {
  document.getElementById(id).classList.add('hidden');
  document.getElementById(id).classList.remove('show');
}
```

#### Utility Functions
- `escapeHtml(str)` - XSS prevention
- `formatDate(str)` - Indonesian date format
- `formatRupiah(num)` - Currency formatting
- `showToast(msg, type)` - SweetAlert2 toast
- `setVal(id, val)` - Safe input value setter

### 4. Tab-Specific Modules (each in own IIFE or namespace)

#### Dashboard Module
- `loadDashboardStats()` - Fetch stats, chart data, KPI summary
- `renderAttendanceChart(data)` - Chart.js line chart
- `renderKpiChart(data)` - Chart.js bar chart
- `switchChart(type)` - Weekly/Monthly toggle

#### Access Module
- `loadAccessTab()` - Load tenant options, access list
- `onAccessTenantChange()` - Update jabatan preview (SDM Pusat vs SDM Sekolah)
- `searchAccessTeachers()` - Debounced search
- `assignSdmAccess()` - POST to API
- `loadSdmAccessList()` - Render table with revoke buttons

#### Teacher Module
- `loadTeacherTab()` - Load filter options, teacher list
- `loadTeacherList(page)` - Paginated fetch with filters
- `showTeacherModal(id)` - Add/Edit modal
- `closeTeacherModal()` - Reset form
- `saveTeacher(e)` - Form submit (POST/PUT)
- `showTeacherDetail(id)` - Detail modal
- `deleteTeacher(id)` - Soft delete (nonaktifkan)

#### KPI Module
- `switchKpiView(view)` - Overview/Template/Period sub-tabs
- `loadKpiPeriods()` - Period select + table
- `loadKpiTemplates(kategori)` - Template table
- `loadKpiOverview()` - By jabatan + input table
- `loadKpiInputTable(teacherId, periodId)` - Editable inputs
- `saveKpiScores()` - Bulk save with progress
- Modal handlers: `showKpiTemplateModal`, `saveKpiTemplate`, `deleteKpiTemplate`, `showKpiPeriodModal`, `saveKpiPeriod`, `deleteKpiPeriod`

#### Attendance Module
- `loadAttendanceLogs()` - Filtered table
- `loadAttendanceRecap()` - Monthly recap
- `loadManualAttendance()` - Grid view
- `openManualAttendanceModal()` - Add manual attendance
- `saveManualAttendance()` - POST

#### Payroll Module
- `loadPayroll()` - Calculate & render table
- `exportPayrollExcel/PDF()` - Export handlers

#### KAFALAH Module
- `previewKafalah()` - Calculate preview
- `regenerateKafalah()` - Recalculate
- `sendKafalahWhatsApp(target)` - WA integration
- `exportKafalahExcel()` - Export
- `loadKafalahHistory()` - History modal
- `loadKafalahSettings()` - Settings form load/save
- `kafalahOnSettingsContextChange()` - Toggle Pusat/Sekolah mode

#### Settings Module
- `loadPaymentSettings()` - Potongan/Tunjangan
- `loadKafalahSettings()` - KAFALAH component settings
- `loadKafalahKenaikan()` - Kenaikan settings
- `loadJabatanTunjangan()` - Jabatan tunjangan
- `loadPendidikanRef()` - Pendidikan reference

## Implementation Order

1. **Create HTML skeleton** - Structure, tabs, modals (all with `hidden` class)
2. **Create CSS file** - Minimal utilities
3. **Create JS core** - State, API, tab system, modal helpers, utils
4. **Implement each tab module** - One at a time, test before next
5. **Wire up all event listeners** - Delegated where possible
6. **Integration testing** - Full flow verification
7. **Polish** - Loading states, error handling, empty states

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| API endpoints missing | Document required endpoints, mock if needed during dev |
| Modal z-index conflicts | All modals use `z-50`, ensure no higher z-index elements |
| Chart.js memory leaks | Destroy charts before re-render (`chart.destroy()`) |
| Large KAFALAH table horizontal scroll | Use `overflow-x-auto` wrapper, test on mobile |
| Token expiry during session | API wrapper handles 401 → redirect to login |
